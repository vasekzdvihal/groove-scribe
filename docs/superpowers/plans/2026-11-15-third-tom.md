# Third Tom Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the note grid a Mid tom row (GrooveScribe's tom 2 lane), so the grid shows High tom, Mid tom and Floor tom.

**Architecture:** Tom 2 becomes a grid lane like tom 1 and tom 4: a row in `js/viewHtml.js`, set/get through `set_tom_state` / `get_tom_state`, loaded from URL and ABC, read back into `toms_array[1]`. `class_kept_toms` keeps only tom 3 from then on. Sheet music, MIDI and the URL format do not change.

**Tech Stack:** Native ES modules, no build. Vitest (jsdom) in `tests/`, Playwright in `tests-e2e/`.

**Spec:** `docs/superpowers/specs/2026-11-15-toms-layout-part-play-design.md`, Part 1.

## Global Constraints

- SVG and MIDI output of every groove stays byte-identical. The golden master proves it. Never add or commit `*-chromium-darwin*` files.
- Touch targets are at least 44 px. Check at 1024x768, 768x1024 and 1440x900.
- User-facing text is Simplified Technical English.
- Grid colours change in `css/` and `js/constants.js` together. This plan adds no colour.
- Do not edit vendored files (`js/vendor/`, the files in the `knip.json` `ignore` list).
- Row order, top to bottom: Hi-hat, High tom, Mid tom, Snare, Floor tom, Kick.
- Labels: `High tom`, `Mid tom`, `Floor tom`.
- Mid tom = lane T2: ABC `constant_ABC_T2_Normal` (`'d'`), MIDI `constant_OUR_MIDI_TOM2_NORMAL` (47).
- Tom 3 (T3) gets no row. Its notes stay kept and play as today.
- Work in `/Users/vasekzdvihal/source/GitHub/groove-scribe-worktrees/feat-third-tom` on branch `feat/third-tom`. Run `npm run verify:fast` before each commit.

## Review Focus

1. **A groove with no T2 notes must give the same SVG, MIDI and URL as before.** `toms_array[1]` becomes a full-length array of `false` where it was `[]`. Test: the golden master (Task 3), plus a unit test that the URL of a T1/T4-only groove has no `&T2=` (Task 1).
2. **A shared link with T2 and T3 notes** must keep both lanes through a round trip. T2 shows in the grid, T3 stays kept. Test in Task 1.
3. **Bar changes with T2 notes:** add a bar, remove a bar, change the time signature or the division. The mid tom notes must survive, the same way tom 1 and tom 4 notes do. Test in Task 2.
4. **Mute the Mid tom row in one bar:** its notes must not play in that bar. Test in Task 2.
5. **Clear all notes** must clear the Mid tom row and the kept tom 3 lane. Test in Task 2.
