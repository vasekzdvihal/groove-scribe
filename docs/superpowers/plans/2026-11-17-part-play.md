# Part play Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Select some beats of the groove on a ruler above each bar, and loop only those beats.

**Architecture:** The selection is a range of global beat indices, held by GrooveWriter. Pure
helpers in `js/partPlay.js` turn it into one slot range per bar, a chip label and a playback
percent. The existing per-bar MIDI builder gets an optional slot range, so the click and swing
use the real position in the bar. A small controller (`js/partPlayControl.js`) reads pointer
input on the rulers and draws the chip in the metronome bar.

**Tech Stack:** native ES modules, no build step; Vitest (jsdom); Playwright e2e.

**Spec:** `docs/superpowers/specs/2026-11-15-toms-layout-part-play-design.md`, Part 3.

## Global Constraints

- SVG and MIDI output of a groove stays byte-identical (golden master). Part play builds a
  separate MIDI file only for playback; it never changes the groove, the URL or the saved data.
- Touch targets at least 44 px. Check at 1024x768, 768x1024 and 1440x900.
- All user-facing text is Simplified Technical English.
- Do not edit vendored files (`js/vendor/`, files in `knip.json` `ignore`).
- Do not edit the player markup shared with the embed pages; change it in the editor only.
- A new `js/*.js` module goes into the module list in `eslint.config.js`. A module that
  `main.js` imports gets a `modulepreload` link in `index.html` (`tests/preload.test.js`).
- Run `npm run verify:fast` before each commit; `npm run test:e2e:verify` for js/css/html work.

## Decisions by the user

- **D1 = A (2026-11-17).** The Remove bar × stays at the top right of the header row, over the
  right end of the ruler. The last beat is tapped left of the ×. Rejected: × in the label column
  with a double tap for a whole bar (B), × below each bar (C).

## Data model

- `BeatRange = { first: number, last: number }`: global beat indices, inclusive,
  `first <= last`. Global beat = `measureIndex * numBeats + beatInBar` (0-based).
- `numBeats` = time signature top. Beats are equal parts of the bar. The ruler shows only when
  `notesPerMeasure % numBeats === 0` (every beat is whole grid cells).

## Review Focus

1. Undo or redo of a note edit keeps the selection; undo of an added bar clears it (the shape
   changed). Test in Task 3.
2. Swing and the click inside a half bar sound the same as in the full groove: the note times
   of a slot range equal the same slots of a full bar. Test in Task 2.
3. A click offset ("start click on the &") with a selection that starts on beat 3. Test in
   Task 2.
4. A muted instrument in a selected bar stays muted. Test in Task 3.
5. A drag that leaves the ruler, or a pointer cancel (a scroll gesture), ends the drag at the
   last beat it crossed and never sticks. Test in Task 4.
